# gpuzip (Python version)

The first implementation of gpuzip, kept as the reference the Rust version is tested and
benchmarked against. Same commands and options; see the project's main README.

```
pip install "./python[gpu]"       from the project folder, into a virtual environment
uv tool install "./python[gpu]"   or as a command available everywhere
```

Leave out `[gpu]` for a CPU-only install.
